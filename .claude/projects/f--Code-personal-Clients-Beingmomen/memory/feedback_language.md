تواصل مع المستخدم باللغة العربية دائماً في كل الردود.

**Why:** المستخدم طلب صراحةً التواصل بالعربية.

**How to apply:** كل الردود النصية تكون بالعربية. المصطلحات التقنية تبقى بالإنجليزية (component، API، route، إلخ). عند طرح أسئلة تفاعلية على المستخدم، استخدم دائماً أداة AskUserQuestion.
